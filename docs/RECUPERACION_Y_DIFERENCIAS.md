# Recuperación y diferencias

## Evidencia recuperada

- Paquete `SIGPI_Prototipo_Opcion_C_v0.1.zip` localizado en `08_Herramientas_y_Prototipos` y en `06_SIGPI_Software`.
- Código React/Vite, estilos, mapa de Paraguay, pruebas de empaquetado y documentación de QA.
- Decisión visual Opción C: inteligencia territorial con shell institucional verde azulado.
- Nueve registros históricos y reglas de calidad del dato.
- Archivo `Compartir_SIGPI.html`, que era una tarjeta de acceso y no una copia funcional.

No se recuperó una versión v0.3 previa ni un repositorio GitHub SIGPI. El enlace histórico `sigpi-paraguay.condeclo.chatgpt.site` no pudo verificarse como accesible mediante las herramientas de recuperación.

## Componentes preservados

- identidad visual Opción C;
- navegación lateral, barra de procedencia, tarjetas, tablas y detalle;
- base histórica y estados de calidad;
- mapa nacional y marcadores referenciales;
- compatibilidad de empaquetado original.

## Implementación nueva v0.3

- Dashboard consolidado.
- CRUD local de parques y proyectos.
- importación y validación de GeoJSON;
- polígonos sobre mapa simplificado;
- gestión de metadatos documentales;
- matriz de evaluación editable;
- CSV, impresión/PDF y respaldo JSON;
- separación visual pública/interna;
- workflow de GitHub Pages;
- documentación de arquitectura, seguridad, pruebas y mantenimiento.

## Cambio de alcance deliberado

La v0.1 mostraba varios módulos como pantallas pendientes. La v0.3 reemplaza esas pantallas por flujos funcionales, manteniendo etiquetas claras para toda capacidad que requiere backend. No se inventaron permisos efectivos, persistencia multiusuario ni estadísticas oficiales actuales.
